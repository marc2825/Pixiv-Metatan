# Independent synthetic reference fixtures

All committed images are generated by us: 1×1 black pixels plus test-only metadata. They are not actual NovelAI generations or third-party artwork. `Software=NovelAI` is a self-reported synthetic test claim. No valid NovelAI signature is included.

The ordinary PNG fixtures are written with Pillow, then read by unmodified `nai_sig.extract_png_text_metadata` / `Metadata.decoded_comment` from [NovelAI's reference](https://github.com/NovelAI/novelai-image-metadata/tree/3428907ac7183d7e36d7cc39e8f46f6f35ce99c1). A 64-byte zero signature is rejected by its verifier; our app reports it unverified because our verifier is not implemented. There is no cryptographically valid positive test here.

`comfy-saveimage.png` is produced by the unmodified `SaveImage` class extracted from [ComfyUI nodes.py](https://github.com/Comfy-Org/ComfyUI/blob/d07dff4565ea9804277fff8cdfa0c817e08c3d44/nodes.py). Only tensor and output-directory adapters are supplied; the server and generation model are not run. Complete prompt/workflow strings are expected without graph interpretation.

Reference source is downloaded outside the repository and is not included in the extension. NovelAI reference code is MIT; ComfyUI source has its upstream licensing. No third-party source code is copied into this fixture directory. Expected metadata and source SHA-256 values are in `fixtures/expected.json`.

To reproduce, obtain the following fixed source files into a temporary directory:

- NovelAI commit `3428907ac7183d7e36d7cc39e8f46f6f35ce99c1`: `nai_sig.py`, `nai_meta.py`.
- ComfyUI commit `d07dff4565ea9804277fff8cdfa0c817e08c3d44`: `nodes.py` saved as `comfy_nodes.py`.

Use a temporary Python environment with Pillow, NumPy, PyNaCl and PyYAML. Then run:

```bash
python scripts/reference-fixtures.py --source-dir /tmp/pami-reference-source
npm test
npm run test:extension
```

The script checks source hashes before executing the official local reader/writer. It generates six synthetic files and records independent expected fields. The JavaScript tests can then run offline from these files without Python dependencies. NovelAI cloud Inspect, real signed images, JPEG/WebP EXIF, Stealth, and V4/V5 character captions remain outside this comparison.
