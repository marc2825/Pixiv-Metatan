# Independent synthetic reference fixtures

Every file here was generated by us: black 1×1 pixels, or small deterministic gradients, plus test-only metadata. None is a real generation or third-party artwork. `Software=NovelAI` is a synthetic, self-reported claim. No valid NovelAI signature is included.

Each fixture is written, and then read back, by **unchanged upstream code** before its expected values are recorded in `expected.json`. Only small functions/classes are executed, with stub adapters for paths and settings. No model, account, cloud service, ComfyUI server or Stable Diffusion WebUI is run.

| Fixtures | Writer | Independent read-back |
|---|---|---|
| `novelai-normal.png`, `novelai-wrapped-comment.png`, `novelai-invalid-signature.png` | Pillow `PngInfo` | NovelAI `nai_sig.extract_png_text_metadata` / `decoded_comment`; zero signature rejected by `nai_sig.verify_metadata_is_novelai` |
| `novelai-stealth-only.png` (160×48, alpha only), `novelai-v4-text-and-stealth.png` (128×128, text + alpha) | NovelAI `nai_meta_writer.inject_data` | NovelAI `nai_meta.extract_image_metadata` |
| `rgba-pattern-no-stealth.png` | Pillow | NovelAI `nai_meta` must fail to find the magic |
| `comfy-saveimage.png` | ComfyUI `SaveImage` (nodes.py) | Pillow text chunks |
| `comfy-exif.webp` | ComfyUI `ImageSaveHelper._create_webp_metadata` (comfy_api/latest/_ui.py) + the same Pillow save call | Pillow `getexif()` |
| `a1111-exif.jpg`, `a1111-exif.webp` | AUTOMATIC1111 v1.10.1 `save_image_with_geninfo` | AUTOMATIC1111 `read_info_from_image` |
| `no-metadata.png`, `synthetic.jpg` | Pillow | — |

V4/V4.5 character captions follow the official NovelAI image API schema (`RequestParameters.v4_prompt` → `V4ConditionInput`). That schema is recorded with its SHA-256 in `expected.json`; it is not executed.

Pinned sources (hash-checked by the script before anything runs):

- NovelAI commit `3428907ac7183d7e36d7cc39e8f46f6f35ce99c1`: `nai_sig.py`, `nai_meta.py`, `nai_meta_writer.py` (MIT).
- ComfyUI commit `d07dff4565ea9804277fff8cdfa0c817e08c3d44`: `nodes.py` saved as `comfy_nodes.py`; `comfy_api/latest/_ui.py` saved as `comfy_ui.py` (GPL-3.0).
- AUTOMATIC1111 stable-diffusion-webui v1.10.1 commit `82a973c04367123ae98bd9abdf80d9eda9b910e2`: `modules/images.py` saved as `a1111_images.py` (AGPL-3.0).

Upstream source is downloaded to a temporary directory outside the repository. It is not copied into the extension or into this repository.

## Reproduce

```bash
mkdir -p /tmp/pami-ref && cd /tmp/pami-ref
N=https://raw.githubusercontent.com/NovelAI/novelai-image-metadata/3428907ac7183d7e36d7cc39e8f46f6f35ce99c1
C=https://raw.githubusercontent.com/Comfy-Org/ComfyUI/d07dff4565ea9804277fff8cdfa0c817e08c3d44
A=https://raw.githubusercontent.com/AUTOMATIC1111/stable-diffusion-webui/82a973c04367123ae98bd9abdf80d9eda9b910e2
curl -fsSLO $N/nai_sig.py -fsSLO $N/nai_meta.py -fsSLO $N/nai_meta_writer.py
curl -fsSL $C/nodes.py -o comfy_nodes.py && curl -fsSL $C/comfy_api/latest/_ui.py -o comfy_ui.py
curl -fsSL $A/modules/images.py -o a1111_images.py
python3 -m venv venv && venv/bin/pip install pillow numpy pynacl pyyaml piexif
cd -  # back to the repository
/tmp/pami-ref/venv/bin/python scripts/reference-fixtures.py --source-dir /tmp/pami-ref
npm test && npm run test:extension
```

The script regenerates all fixtures. On 2026-11-19 (Pillow 13.0.0, NumPy 2.5.5, piexif 1.1.3) the six older files were reproduced byte-for-byte. The JavaScript tests run offline from the committed files without Python.
