## Development dependencies (not distributed)

Every npm package is a `devDependency` for building and testing (TypeScript, WXT, Vite, Vitest, jsdom, Playwright and what they pull in). Their licenses are MIT, Apache-2.0, ISC, BSD-2/3-Clause, 0BSD or BlueOak-1.0.0, except `lightningcss` (MPL-2.0), a CSS tool Vite runs at build time. None of its code ends up in the extension. The committed fixtures are tiny generated images (black pixels or gradients) with text we wrote. See [tests/reference/README.md](tests/reference/README.md).
