## Development dependencies (not distributed)

All npm packages are `devDependencies` used to build and test the extension (TypeScript, WXT, Vite, Vitest, jsdom, Playwright and their transitive dependencies). Their licenses are MIT, Apache-2.0, ISC, BSD-2/3-Clause, 0BSD or BlueOak-1.0.0. The exception is `lightningcss` (MPL-2.0), a CSS tool used by Vite at build time; none of its code is included in the extension. There is no GPL or AGPL package in the dependency tree. Check with `npm ls` and the `license` fields in `package-lock.json`.

`scripts/reference-fixtures.py` downloads these sources at runtime into a temporary directory, checks their SHA-256, and extracts only the named functions for execution. The committed fixtures are tiny synthetic images (black pixels or gradients) with synthetic text that we chose; see [tests/reference/README.md](tests/reference/README.md).
