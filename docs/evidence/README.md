The reports identify generated manifest/background/content-script bytes by SHA-256. They do not include private URLs, images, prompts, credentials, raw request headers or HARs. Full transient Playwright reports remain ignored under `.verification/`.

In the synthetic report, `configuredStatus` is the fixture's planned response; `status`/`mime` come from actual browser response events. A cancelled or timed-out request may have a configured status but no observed status. `outcome` distinguishes finished and failed requests.

The live command intentionally exits nonzero on denied document access. It never changes headers, imports authentication, proxies requests, or retries to turn a failure into success.
