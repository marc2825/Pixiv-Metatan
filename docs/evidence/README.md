# Verification evidence

Sanitized status evidence only. Nothing here contains images, prompts, artwork IDs or URLs, credentials, raw request headers, HAR files or local paths.

| File | What it shows |
|---|---|
| `live-layers-2026-11-19.json` | Layer-by-layer live diagnosis: headless-browser document 403 caused by a Cloudflare managed challenge; plain-HTTP document 200; pages API 200 with URL shapes matching the validators; original and derivative **403 without Referer** (the worker's request profile). No forged headers; HEAD requests only for images. |
| `live-referer-2026-11-22.json` | After the maintainer decision (issue #9): the same original returns 403 without and 200 with `Referer: https://www.pixiv.net/` (no cookies). The production build's worker fetch with the session rule returns 200 in Chromium 156, and a page `<img>` is not affected by the rule. No artwork ID, URL or bytes recorded. |
| `live-connectivity-2026-11-19.json` | `npm run verify:live` against the top page in a fresh headless profile: document 403 classified as `cloudflare-managed-challenge`. No API/original request; exits non-zero by design. |
| `mv3-synthetic-2026-11-19.json` | Production MV3 build in disposable profiles; every page/API/image response intercepted and generated by us. Per-test network records (kind, worker or page, status, MIME, page) and build SHA-256. Not evidence of real pixiv access. |
| `live-connectivity-2026-11-15.json`, `mv3-synthetic-2026-11-15.json` | The previous run, kept for comparison. Superseded by the 2026-11-19 files. |

In synthetic records, `configuredStatus` is the planned fixture response, while `status`/`mime` come from browser response events. A cancelled or timed-out request may have a configured status but no observed status. `outcome` distinguishes finished from failed requests.

The live command never changes headers, imports authentication, proxies requests, retries, or solves bot challenges to turn a failure into success. Older evidence (2026-10-23) is in git history.

Regenerate the synthetic file after `npm run test:extension` with:

```bash
node scripts/export-synthetic-evidence.mjs docs/evidence/mv3-synthetic-YYYY-MM-DD.json
```
