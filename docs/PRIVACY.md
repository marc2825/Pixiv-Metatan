# プライバシー説明

2026-10-22 / 開発版0.1.0

本拡張は、ユーザーが現在閲覧中のpixiv作品で明示的に選択した1枚、またはユーザーが選択したローカルファイルを端末内で解析します。

- パネルを開く、または「画像一覧を取得」を押すと、現在の作品のpixiv APIへ1回リクエストします。通常の同一オリジンセッションをブラウザが利用します。Cookie・パスワード・認証トークンを読み出しません。
- 「元画像を検査」を押すと、APIから得た対象のi.pximg.net原寸URLへ1回リクエストします。認証情報を付けず、リダイレクトを追跡しません。pixiv/pximgには通常の通信に伴うIPアドレス等が伝わります。
- 検査画像、Prompt、生成設定、ローカルファイル名を外部サーバーに送信しません。テレメトリー・アクセス解析・広告SDKはありません。
- 結果は表示中のメモリ上に保持し、localStorage、拡張ストレージ、ファイル、データベースへ保存しません。作品変更・タブ破棄で破棄します。ブラウザ自体の通常HTTPキャッシュは利用される場合があります。
- コピーはユーザーが押した場合だけ行います。クリップボードの保存・履歴・同期はOS/ブラウザの設定に従います。正規化JSONにはRAWと解析対象URLまたは選択ファイル名を含みます。
- 必要なホスト権限はwww.pixiv.netとi.pximg.netだけです。他サイト、履歴、Cookie、ストレージ、ダウンロード一覧を読みません。
- 一括巡回、検索結果の走査、画像先読み、ログイン・年齢・アクセス制限の回避はありません。

公開前の実機検証は未完了です。実装上の制限・検証状況は[TEST_STATUS.md](TEST_STATUS.md)に記録しています。
