# スクリーンショット

どれも `npm run test:browser` で、合成ページから撮ったものです。ページは自分で書いたHTMLで、画像はテストが返す1×1の黒いPNGです。実際のpixivのDOMや他の人の画像は写っておらず、実際のpixivで動いたことを示すものでもありません。

- `hover-result.png`（1100×850）: 複数枚の作品のプレビューで、2ページ目の「生成情報を見る」を押したところ。結果は画像の横に出ます。NovelAI風の合成テキストを読んでいます。
- `hover-light.png`、`hover-dark.png`（360×640）: 画面の端近くで開いた1枚の作品のプレビュー。pixivのテーマに関係なく同じ見た目なので、ライトとダークの差はページ側だけです。
- `synthetic-dark-mobile.png`（360×640）: 作品ページの「生成情報」ボタンから開いたプレビューと結果。狭い画面では結果が画像の下に出ます。
- `local-inspector.png`（1100×850）: 拡張機能のアイコンから開く検査ページ。2枚の画像を入れ、2枚目の結果を表示したところ（`npm run test:extension` で撮影）。

2026-11-24にUIを作り直したあとで撮り直しました。

テスト用のアダプタは、アクセシビリティのロケーターを使うためにShadow Rootをopenにしています。本番のビルドはclosedで、そちらは `npm run test:extension` で確かめています。
